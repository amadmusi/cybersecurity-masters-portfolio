# cybersecurity-masters-portfolio
This repository showcases selected projects and technical work completed during my Master’s in Cybersecurity with a concentration in IT Management at Southern New Hampshire University (SNHU). The portfolio demonstrates practical experience in cybersecurity risk management, network assessment and defense, digital forensics, human factors in security, and enterprise IT.


## Projects

### 1. [Network Assessment & Defense](network-assessment-defense)

Security-focused network assessment and defense project demonstrating practical analysis of network infrastructure, vulnerabilities, traffic, and defensive security controls.

**Key Areas:** Network Security • Network Assessment • Traffic Analysis • Defensive Security

### 2. [Enterprise Network Security Design](enterprise-network-security-design)

Designed and evaluated a secure, scalable multi-site enterprise network for a fictional organization expanding across Dallas, Memphis, Houston, and Kansas City. The project includes network traffic analysis, VLAN segmentation, subnetting, SD-WAN, VPN connectivity, redundancy, IDS/IPS, SIEM, centralized authentication, and enterprise network architecture.

**Key Areas:** TCP/IP • VLANs • Subnetting • SD-WAN • VPN • OSPF • Firewalls • IDS/IPS • SIEM • Active Directory • RADIUS • Wireshark • QoS
